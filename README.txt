Y_eld. offline app (installable PWA)

1. Upload all files in this folder (keep them together) to any HTTPS static host: Netlify Drop, GitHub Pages, or Cloudflare Pages.
2. On her phone, open the link once with internet.
   iPhone: Safari > Share > Add to Home Screen.
   Android: Chrome > menu > Install app.
3. Open it from the home-screen icon. After that it works fully offline.

Notes: all data stays on that one phone (no sync). Clearing app data or deleting the app erases it, so use Settings > Show my data to keep a copy now and then.
